# GreasyPidgin

Algorithmic composition toolkit, implemented in several languages.

| folder      | contents                                                   |
|-------------|------------------------------------------------------------|
| `python/`   | reference implementation (most up to date), pip package    |
| `lua/`      | Pure Data objects (pdlua)                                  |
| `js/`       | Max `[js]` code                                            |
| `shared/`   | MIDI, sound, PDF, images and text used across languages    |
| `tutorial/` | GreasyPidginTutorial, separate repo (not tracked here)     |

Python install: see [`python/README.md`](python/README.md).
